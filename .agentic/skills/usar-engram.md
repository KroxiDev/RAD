# Usar Engram

Para recuperar contexto o guardar hallazgos entre sesiones, seguir el protocolo de Engram
disponible en el entorno. Esta skill no instala ni configura la integración.

1. Buscar contexto relevante del proyecto actual con `mem_context` o `mem_search`; ampliar
   los hallazgos con `mem_get_observation`.
2. Contrastar los recuerdos con el estado actual del proyecto antes de usarlos como evidencia.
3. Guardar decisiones, convenciones y hallazgos duraderos con motivo y fuentes según el
   protocolo y las autorizaciones vigentes del entorno. Excluir secretos y evitar copiar
   la memoria al repositorio.
4. Si Engram no está disponible, continuar con las fuentes del proyecto e informar la limitación.
